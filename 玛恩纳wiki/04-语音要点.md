# 语音要点

完整多语对照见 [PRTS 语音记录](https://prts.wiki/w/玛恩纳/语音记录)。这里按条目整理人物线索，只保留必要短句。

时装「远路」带特殊语音，条目结构与默认相同，对象和语气更贴游侠时期。

## 「远路」语音（部分）

对象更具体，时间线更早或更野外。

| 条目 | 要点 |
| --- | --- |
| 任命助理 | 「只是下了场雨而已。」 |
| 交谈 1 | 对托兰：从没保证跟着他就有活路。猎人们的死不必被轻描淡写。托兰会记得，他也会。 |
| 交谈 2 | 对切斯柏：权贵倾轧只是换成投机牟利。无辜者仍被株连。你为什么不逃得更远。 |
| 交谈 3 | 理想已经终结。想练骑士格斗就拿起枪，别把未来托付给失败者。 |
| 晋升后交谈 1 | 对父亲：国民院冤案、商业联合会崛起，想阻拦的都无法被杀死。斩不去病灶，看着斯尼茨离去，只是习惯了这把剑。 |
| 晋升后交谈 2 | 金色平原、麦田、航道、天灾痕迹、庄园、竞技场、交出最后收成的人们。他一直走在同一条路上。 |
| 信赖 1 | 对斯尼茨：不能替他们教导玛莉娅。他不是骑士，也不是父亲，并不温柔。为什么留下的是他。 |
| 信赖 2 | 对约兰塔：玛嘉烈不跟他说话，只是当时性格如此。她太像年轻时的约兰塔，会亲身经历，也从不后悔。 |
| 信赖 3 | 大骑士领日新月异，二十年前的日落剪影已无痕迹。他仍想至少把过去找回来。 |
| 闲置 | 「旷野上的风雨声……」 |
| 干员报到 | 「不畏苦暗」……一个并不值得怀念的时代。太过清醒的梦。 |
| 精一晋升 | 斯尼茨总寄骑士团空白擢升文书和侦察报告来打招呼。 |
| 精二晋升 | 他该看起来像报纸上的污蔑，还是像那个把敌视当作头衔的游侠。 |
| 信赖触摸 | 别往剑上加装饰，托兰。想借「临光」之名的商人会替他嘲弄这件事。 |
| 问候 | 不是怀念，只是不能忘记灯光照不到的地方那些无能为力的事。 |
| 新年 | 荒地跋涉谁还记得日期。但大骑士领的一切都按报纸上的日子计算。 |
| 生日 | 不再许愿的人也不再期待生日。他很久没对人说过生日快乐。 |
| 周年 | 并非只有理想主义者才会前行。 |

## 语音里反复出现的人

- **玛嘉烈 / 玛莉娅**：保持距离，却把责任和远游当作教育。
- **西里尔**：父亲、家训、长剑、无法斩去的病灶。
- **斯尼茨 / 约兰塔**：失踪的兄嫂；家书；「为什么是我留下」。
- **托兰**：旧日同伴，赏金猎人。死亡、装饰、挖苦。
- **切斯柏**：旧识。父母因叛国骑士家臣身份被迫出逃。
- **博士**：一意孤行的同行者，不是他要效忠的理想。
