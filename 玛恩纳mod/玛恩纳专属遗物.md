# 玛恩纳：专属遗物

8 件专属遗物，对齐塔 2 原版角色池（铁甲 / 静默 / 故障 / 缚亡 / 摄政都是 8 件含起始）。规则跟 [玛恩纳末端卡牌与机制设计.md](玛恩纳末端卡牌与机制设计.md)，关键字跟 [玛恩纳色卡牌面.md](玛恩纳色卡牌面.md)。不写实现。

已锁 4 件不动：未开刃的家传剑、垫座的报纸、被磨利的剑、空白擢升文书。再留 4 件补形状。数字是**工作值**。

档位对齐原版，不设角色专属 Boss 遗物：起始 1、普通 1、罕见 2、稀有 3、店 1。

---

## 0. 边界

- 不增加第 5 个拔剑入口。
- 遗物里的**不重置**只有「被磨利的剑」。
- 加长窗口的只有「空白擢升文书」（店；本场第一次拔剑 +1 回合）。
- 不引入第二货币。共享遗物走原版池。
- 不要靠遗物把「不会蓄势」变成自动满。

---

## 1. 起始

### 1. 未开刃的家传剑
- **ID**：`mlynar_relic_unsharpened_sword`
- **起始**
- **效果**：每场战斗开始时，蓄势 +2。
- **职责**：第 2～3 回合就有值得拔的一刀。
- **出处**：`玛恩纳wiki/05-模组与皮肤.md` 车库里那柄不必开刃的家传剑。
- **为什么是这个效果**：剑还在鞘里，人已经带着一半力气上场。大号是稀有牌「鞘中人」。

---

## 2. 普通

### 2. 垫座的报纸
- **ID**：`mlynar_relic_newspaper`
- **普通**
- **效果**：每个鞘中回合，你第一次打出非攻击牌时，蓄势 +1。
- **职责**：教「坐班也在蓄」。吃技能，不吃刀。
- **出处**：`玛恩纳wiki/05-模组与皮肤.md`：垫在车座下的旧报纸，把文字填进自己。
- **为什么是这个效果**：翻一页纸，气球人多灌一点。拔着剑的时候不读报。

---

## 3. 罕见

### 3. 始终在身边
- **ID**：`mlynar_relic_always_at_side`
- **罕见**
- **效果**：每场战斗开始时，若抽牌堆有拔剑牌，将其中 1 张放到抽牌堆顶。
- **职责**：帮你摸到窗口，不新增入口。
- **出处**：`玛恩纳wiki/01-基础信息.md` 招聘合同：始终将剑带在身边。
- **为什么是这个效果**：剑一直在。不是多开一扇门，是把手按到鞘上。

### 4. 磨淡的字
- **ID**：`mlynar_relic_faded_words`
- **罕见**
- **效果**：每当你收剑，获得 5 点格挡。
- **职责**：窗口结束还能站住。不留蓄势，不当不重置。
- **出处**：`玛恩纳wiki/剧情/01-背景与编年.md`：家训还在剑上，他每天把字磨得快看不清。
- **为什么是这个效果**：字淡了，人还在。收回去的那一下，是家训剩下的厚度。

---

## 4. 稀有

### 5. 被磨利的剑
- **ID**：`mlynar_relic_honed_sword`
- **稀有**
- **效果**：每场战斗第一次收剑时，不重置。
- **职责**：遗物里唯一的不重置。一次，不是永续。
- **出处**：`玛恩纳wiki/剧情/02-活动细纲.md` 「空盔甲」：取回被切斯柏磨利的佩剑。
- **为什么是这个效果**：他还回来的不是封号，是刃。第一次收回去，力气还在。

### 6. 侦察报告
- **ID**：`mlynar_relic_scout_report`
- **稀有**
- **效果**：每个回合开始时，预见 1。
- **职责**：每回合看一步。寻路引擎，不是过牌狂欢。
- **出处**：`玛恩纳wiki/剧情/01-背景与编年.md`：斯尼茨会寄侦察报告里「有关我们动向」的部分来打招呼。空文书是店遗物。
- **为什么是这个效果**：哥哥留下的是方向，不是剑。每回合先看一眼该不该走。

### 7. 已然受训
- **ID**：`mlynar_relic_already_trained`
- **稀有**
- **效果**：进入拔剑时，窗口加值额外 +2（不受蓄势上限限制）。
- **职责**：让窗口更亮，不更长。
- **出处**：`玛恩纳wiki/剧情/02-活动细纲.md` 「空盔甲」：卡西米尔无权为我授勋，卡西米尔已然为我受训。
- **为什么是这个效果**：受训的是这一刀有多重，不是他该不该被授勋。

---

## 5. 店

### 8. 空白擢升文书
- **ID**：`mlynar_relic_blank_commission`
- **店**
- **效果**：每场战斗第一次进入拔剑时，该窗口持续 +1 回合。
- **职责**：第一次窗口更长。对应原版硫磺 / 忍者卷轴这一档，不进 Boss 池。
- **出处**：`玛恩纳wiki/剧情/01-背景与编年.md`：斯尼茨寄骑士团空白擢升文书当问候。
- **为什么是这个效果**：空文书授不了勋，只能把这一次拔剑多留一拍。

## 6. 审计

### 6.1 不重置 / 窗口

| 事 | 来源 |
| --- | --- |
| 不重置 | 只有被磨利的剑 |
| 窗口 +1 回合 | 只有空白擢升文书 |
| 窗口加值额外 +2 | 只有已然受训 |
| 第 5 个拔剑入口 | 无。始终在身边只检索已有拔剑牌 |

### 6.2 蓄势

| 遗物 | 档 |
| --- | --- |
| 未开刃的家传剑 | 开局 +2 |
| 垫座的报纸 | 鞘中每回合最多 +1 |
| 已然受训 | 不直接给蓄势，给窗口加值 +2 |

上限仍是 8。已然受训的 +2 加在窗口加值上，当次攻击可以超过 8。

### 6.3 和牌的错开

| 牌 | 遗物 |
| --- | --- |
| 鞘中人 | 家传剑更弱（只开局 +2） |
| 磨剑 | 报纸吃非攻击 |
| 给我一把剑 | 始终在身边只检索；被磨利的剑只一次不重置 |
| 日暮寻路 / 家书 | 侦察报告是每回合一眼 |
| 长骑之名 | 文书不加称号，只加长第一次窗口 |

### 6.4 未进池

对齐 8 件后拿掉，不当废稿，也不进奖励池：一行小字、旧日的礼物、没人听见、没有装饰、捎来的信、夜景。
